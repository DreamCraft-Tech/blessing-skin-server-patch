# 6.1.0.1 更新器修复

## 更新任务与下载显示

更新任务摘要保存在当前超级管理员对应的服务端记录中，有效期一小时。Session 仅保存摘要，文件清单保留在服务端运行包目录。确认安装优先检查账户绑定记录，并兼容此前版本的会话任务。任务失效时返回更新页面显示处理结果；角色权限检查保持超级管理员要求。

浏览器通过原下载端点请求 NDJSON 进度流，服务端报告实际接收字节数。已知总长度时显示百分比；未知总长度时显示已接收大小。下载、校验、解压和完成结果分别显示。原 JSON 请求方式继续支持。

HTTP 状态、DNS、TLS、连接超时和下载中断在页面内显示，服务器详细异常写入 Laravel 日志。响应设置 `X-Accel-Buffering: no` 与 `Cache-Control: no-store, no-transform`。CDN / OpenResty 应允许管理路径 POST 请求和流式响应，并对管理路径关闭缓存。

## 已在旧版遇到确认安装 403

旧站执行的是旧版安装器，需要先将 `updater-repair_6.1.0.1.zip` 解压覆盖到站点根目录（含 artisan 的目录），刷新 PHP OPcache / 重启 PHP 服务，然后重新检查更新或上传完整 ZIP 运行包并确认安装。

修复包用于本项目已有 ZIP 更新功能的 6.0.3_patch 至 6.1.0 分支，包含更新控制器、任务存储、运行包校验、上传限制和语言中间件五个 PHP 文件。部署前保留这些文件的副本。完整运行包仍由检查更新页面安装。升级至 6.1.0.1 后启用新版下载进度显示。

修复包的旧版安装路径在替换文件前创建跳转响应并清理模板缓存，以兼容 Laravel 10 到 Laravel 12 的跨框架安装请求。
