## 兼容性适配

- `blessing/filter` 1.4.0、`blessing/rejection` 1.4.0 和 `lorisleiva/laravel-search-string` 1.3.0 尚未声明 Laravel 12。composer.json 使用显式 package 仓库元数据，固定官方源码提交与下载地址，只调整 Illuminate 约束及本地兼容版本标识；原作者、许可证和源码保持原样。这是本项目验证的适配声明。
- Passport 显式加载其迁移并启用既有 password grant；测试覆盖数据库迁移、实际令牌签发和 Bearer API 访问。
- Laravel 12 原生邮箱校验已包含换行拒绝逻辑，应用不再覆盖其验证器。
- AdminLTE 3.2 核心 JS/CSS 随源码保存，避免安装未使用的编辑器等 npm 传递依赖。许可证、来源及逐文件 SHA-256 位于 `resources/assets/vendor/adminlte/UPSTREAM.json`，源码检查验证这些哈希。
- Yggdrasil API 与 Connect 按 JWT 5 不可变构建器保留返回对象；Connect 使用当前验证约束、整数 Carbon 时长及 Passport 配置的密钥来源。对应插件随插件仓库单独发布。

## 应用层修补

- 更新源、插件仓库源和市场安装入口统一要求超级管理员。
- OptionForm 使用严格表单标识比较，阻止 JSON 布尔值触发其他表单。
- ZIP 在写入前校验所有条目，拒绝路径穿越、特殊文件、符号链接目标及重复路径，限制文件数和展开大小。
- 市场下载在仓库提供 SHA-256 时先验证再解压。
- 密码重置与邮箱验证链接使用站点配置域名，避免请求 Host 改写邮件目标。
- HTTPS 判断使用框架的可信代理机制；CDN 插件按验证后的代理链规范化请求协议。

主站 272 项 PHPUnit 测试、366 项 Jest 测试、两套 TypeScript 类型检查和生产 Webpack 构建通过。安装迁移由每项主站及插件集成测试在 SQLite 内存数据库执行，现有更新器还针对完整 ZIP 进行准备与校验。
